# Zoom Earth 주요 기능 정리

출처는 두 가지입니다.
- **[앱 소개]**: 사용자가 공유한 Google Play 앱 소개 화면(2026-10-21)과 사용자 제보. 회사 측 설명이며 직접 검증하지 않은 내용입니다.
- **[관측]**: 웹사이트를 분석하면서 실제 요청과 코드로 확인한 내용입니다. 자세한 근거는 `zoom-earth-typhoon-models.md`에 있습니다.

## 기능별 요약

| 기능 | 앱 소개 내용 | 웹 분석에서 확인한 것 |
|---|---|---|
| **태풍·허리케인 추적** | 발달 단계부터 카테고리 5까지 실시간 추적. NHC, JTWC, NRL, IBTrACS 최신 데이터 사용 | `/data/storms/` JSON에 진로, 예보 지점, 예보 원(cone)이 들어 있음. `agencies` 필드에 "JTWC", "NHC/JTWC"가 표시됨. Invest 단계에는 발달 확률(`chance2day`, `chance7day`)도 있음 **[관측]** |
| **예측 모델 지도** | DWD ICON과 NOAA/NCEP/NWS GFS의 최신 실행으로 갱신 | 모델은 `gfs`, `icon` 두 가지 **[관측]** |
| ├ 강수 | 비·눈·구름을 한 지도에 표시 | R=구름, G=비, B=눈으로 인코딩된 타일 **[관측]** |
| ├ 풍속·돌풍 | 지표풍 평균 속도·방향, 순간 최대풍 | 풍속은 u·v 벡터(10m), 돌풍은 단일 값(지표) **[관측]** |
| ├ 기온·체감·습구온도 | 2m 기온, 체감 온도, 열 스트레스 지역 | 각각 2m 레이어로 존재 **[관측]** |
| ├ 습도·이슬점 | 상대 습도, 이슬점 | 2m 레이어로 존재 **[관측]** |
| └ 기압 | 해면 평균기압 | 해면기압 타일. 등압선과 고·저기압 라벨은 브라우저에서 계산 **[관측]** |
| **위성 이미지** | GOES·Himawari 10분 간격, Meteosat 10분 간격, NASA Aqua/Terra HD 하루 2회 | `geocolor/himawari/...` 타일과 `times/geocolor.json`, `times/gibs.json`(NASA GIBS)을 요청함 **[관측]** |
| **비 레이더·나우캐스트** | 지상 도플러 레이더 실시간 표시와 단기 예보 | `times/radar.json`, `radar/reflectivity/`, `radar/coverage/` 경로를 확인함 **[관측]** |
| **산불 추적** | NASA FIRMS 활성 화재 지점, 매일 갱신 | `/data/fires/latest.json`을 요청함 **[관측]** |
| **맞춤 설정** | 온도·바람 단위, 시간대, 애니메이션 스타일 등 | 설정 키(단위, 애니메이션, 화면 모드 등)가 코드에 있음 **[관측]** |
| **Zoom Earth Pro** | 자동 갱신 구독(Google Play 결제) | 아래 Pro 항목 참고 |

## Zoom Earth Pro와 예보 기간

| | 무료 | Pro |
|---|---|---|
| 모델 예보 기간 | 최신 실행 기준 약 **+58시간**(2.5일) **[관측]** | 최대 **15일 앞까지** **[사용자 제보]** |
| 시간 색인 | `tiles.zoom.earth/times/{model}.json` | `tiles.zoom.earth/times/pro/{model}.json?token=...` **[관측]** |
| 타일 경로 | 같음 | 같음 **[관측]** |

- **[관측]** 2026-10-21 기준 무료 색인의 범위는 다음과 같습니다.
  - GFS·ICON 20일 18Z 실행은 0~58시간, 12Z 실행은 0~64시간입니다. 둘 다 23일 04Z에서 끝납니다.
  - 더 이전 실행은 0~5시간만 남아 있습니다.
- **[관측]** Pro 색인을 토큰 없이 요청하면 HTTP 403이 돌아옵니다.
- **[정적]** 앱은 색인에 있는 시각만 시간 막대(타임라인)에 보여 줍니다(`getForecastRange`). 그래서 예보 기간의 제한은 클라이언트 코드가 아니라 **서버가 내려주는 시간 색인**에서 정해집니다.
- **[추론]** 타일 URL 형식이 같으므로, Pro는 같은 타일 저장소에서 더 긴 예보 시간(`f059` 이후)을 열어 주는 방식으로 보입니다. 다만 15일 범위와 그 이후 타일의 접근 제어는 Pro 토큰이 없어 확인하지 못했습니다 **[미확인]**.
